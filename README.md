# 运气的形状 · The Shape of Luck

一个关于“运气长什么样”的动画网站。运气被画成六个会眨眼、会跳的卡通小家伙：硬币、流星、四叶草、心、骰子和祥云。

## 页面内容

- **首页舞台**：中间的小家伙会在六种形状之间变形，眼睛跟着鼠标转。点「摇一签」它会转起来，最后落在今天的运气形状上，并给出一张签（大吉 / 中吉 / 小吉 / 吉 / 末吉、宜忌、幸运数字和幸运色）。直接戳它也会跳一下。
- **运气图鉴**：六种形状的卡片，每张都有说明、出没地点和稀有度。鼠标放上去会跳起来。
- **接运气**：点草地上方就会掉下一份运气，带简单的弹跳和碰撞物理。
- **片尾**：六个小家伙排队跳波浪。

支持浅色（白天）和深色（夜晚，有星星）两种主题，跟随系统设置；开启“减少动态效果”时动画会收敛。

## 运行

纯静态单文件，没有依赖和构建步骤。直接用浏览器打开 `index.html` 即可，或者：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

也可以直接用 GitHub Pages 发布仓库根目录。

所有角色都是用 Canvas 实时绘制的：每个形状是一组极坐标采样点，形状之间的变形就是逐点插值。
