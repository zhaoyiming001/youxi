# 眠仓计划

网页版宿舍塔防小游戏，玩法参考「躺平发育」：匹配 6 人宿舍，躺在床上赚金币和电力，造建筑守门，赶在鬼越砸越强之前把它打死。手机竖屏优先，电脑也能玩，还能添加到手机桌面当 App 用。

**在线试玩：** https://zhaoyiming001.github.io/youxi/

## 玩法

1. **大厅**：首页是一张专门画的夜景：月亮、星星、飘过的云，一栋亮着灯的卡通宿舍楼（窗户里能看到睡觉的室友），猛鬼绕着楼飘，还有路灯、小树和萤火虫。左上角是头像和段位（点头像换造型），下面是小贴士；右上角只有商城和设置；中间挂着招牌，最下面是开始按钮。
2. **匹配**：自动匹配 5 个室友，名字从 190 多个里随机，头像随机组合 12 种肤色、20 种发色、13 种发型、15 种表情、十几种配饰（帽子、皇冠、口罩、光环、小恶魔角、墨镜等）、雀斑/腮红/创可贴，以及纯色、双色、圆点、圆环背景。室友强弱差距很大，每局随机：神仙（少见，自己就能把鬼打死）、大佬、普通、摸鱼、挂机（几乎不升级，很容易被抓走）。
3. **开局天赋**：匹配成功后发 3 张随机天赋卡，选 1 张（10 秒不选就随机，可以免费换一批），分经济、输出、防守、特殊四类，一共 34 种，比如睡神、暴击、备用门板、冰心、雷达、建筑师等。机器人室友也各有一个，进他房间能看到。
4. **选房（20 秒）**：点一间空宿舍，角色走到床上躺下，开始产金币。室友抢房像真人：有的手快专门抢，甚至跟你抢同一间（谁先躺下归谁），有的犹豫走到一半换房间，有的正常；有的会冒一句话，有的不出声。
5. **成长曲线**（参考原版「每级翻倍」的思路）：床每级收入 ×1.8，门每级血量 ×1.9，炮台和武器每级伤害 ×1.9 左右，升级花费和猛鬼成长同步变陡。**升级门时耐久直接补满**，门快破时升级能救命。
6. **资源**：金币来自床和各种经济建筑；电力来自游戏机、发电机、太阳能板、风车等。
7. **72 种建筑**，每局随机：
   - 6 种基础建筑每局都有：炮台、游戏机、发电机、招财猫、维修台、冰箱。
   - **武器**（34 种）分 5 个品质：普通、精良、稀有、史诗、传说。每局按品质权重随机发 6 种（传说最难出），所以有的局武器很强，有的局要将就着打。武器有子弹、多连发、溅射、激光、喷射、持续毒伤、闪电、按血量上限扣血等，效果有眩晕、减速、破甲、灼烧、给门回血等。
   - **经济 / 防御 / 控制建筑**（38 种）每局各随机 3 种，比如奶茶店、直播间、彩票机、矿机、金蛋鸡、加固板、弹簧门、尖刺陷阱、水晶盾、避雷针、闹钟、全息投影、捕鬼网、灯笼、八卦镜、收音机等。
   - 付费方式分三种：只要金币、金币 + 电力、只要电力。建造面板会标出品质和「本局限定」。
   每个房间的建造格子数量（3～15 个，完全随机）和位置每局都随机，小房间也一定有一个格子在门边，选房时要看清楚。射程从建筑所在的格子算起：门边的格子打得到门口，靠里的格子要放射程远的武器；射程随等级变远，升高后能帮邻居打鬼。**每升一级都换外观**：每一级有自己的配色（原色、暖阳、冰蓝、钢铁、翡翠、赤焰、黄金、紫晶、樱花、钻石），造型也会一级级加东西：Lv.2 铆钉、Lv.3 小旗子、Lv.4 钢底座、Lv.5 小翅膀、Lv.6 尖刺、Lv.7 发光的金底座、Lv.8 王冠、Lv.9 环绕的宝石、Lv.10 彩虹光环。点开建筑能看到当前外观和下一级会变成什么。钱和电够升级时，建筑、床和门上会出现绿色升级箭头。
8. **随机礼盒**：夜里不定时会掉下礼盒（第一个在入夜后 45～90 秒，之后每次隔 1～2.5 分钟），但只有在上一个礼盒之后花过金币或电力才会来，光攒钱不花就没有。14 秒内点开有奖：金币袋、充电宝、修理箱、加班费（收入翻倍）、鸡血（攻速提升）、冰冻弹、升级券。
9. **匹配手气**（参考排位赛的匹配）：不是每局都会触发，但连胜越多，越有可能碰上特别凶的鬼加上拖后腿的室友；连输越多，越有可能碰上没睡醒的鬼加上大佬室友。不会明说，偶尔开局会有一句暗示。
10. **两只鬼**：每局都有两只鬼，两只都打死才算赢。
   - **猛鬼**从楼下鬼井爬出来（见下）。
   - **僵尸**是全新的第二只鬼：入夜后 25～40 秒从楼顶「宿舍 3 楼」路口跳进来，穿清朝官服、戴红顶帽、额头贴黄符，一蹦一跳地走。为了不占顶部位置，它的血条和等级直接显示在它头上（绿色），来砸你的门时会弹提示。它每局从 20 种技能里随机带 4 种：跳砸、尸毒、尸吼、吸阳气、铁甲尸、狂跳、尸气护体、拆门钉、尸寒、引雷、召小僵尸、分尸、夺魂铃、黑雾、腐蚀、震地、缩地、唤醒同伴、定身反噬、血祭；也会随机带一个鬼天赋、叫自己的帮手。残血时逃回楼顶回血。两只鬼会尽量不挤在同一家，炮台优先打最近的那只。
11. **猛鬼**：猛鬼选目标时不会提前告诉你去谁家，只有它开始砸你的门才会报警，要提前把防守做好。难度跟着你的战绩走：段位从新手、见习、熟练、老手、大神到传说，赢得越多猛鬼越强。每砸一次门涨一点经验，砸得越多升得越快、体型越大。Lv.3 学会重击，Lv.5 学会干扰建筑，Lv.8 学会狂暴。残血时会逃回鬼井回血，但**一局最多只能逃 3 次**，三次分别回到 85%、60%、40% 的血，之后就「逃不动了」，只能硬拼到死；12 分钟后也会暴走，不再逃跑。每抓走一个室友，猛鬼立刻升一级，血量 +8%、伤害 +10%（可叠加），体型也会变大，所以弱的室友被吃掉后整栋楼都会更危险。每局猛鬼的底子略有不同（偏强的更多），但不会显示出来。
   - **9 种猛鬼**，每晚随机一种（开局会提示）：普通、隐身、召唤小鬼、拆家、冰霜（冻住建筑）、偷钱、瞬移、分身（残血时分裂出帮手）、尖叫（震停附近建筑）。
   - **16 种猛鬼天赋**，每晚随机一个，显示在顶部血条旁边：铁头、厚皮、飞毛腿、贪吃、学霸、自愈、滑溜、呼朋引伴、嗜血、巨人、灵巧、狡猾、夜魔、诅咒、狂怒、鬼王。
   - **帮手鬼**：猛鬼 Lv.4 起经常叫帮手去砸别人的门（同时最多 2～3 个）。种类随机：帮手、大块头、小恶魔、爆破鬼（冲到门口自爆）、鬼婆（给猛鬼回血）；强度分普通、精英、首领三档，首领比猛鬼本身还强，猛鬼等级越高、吃的人越多越容易出强帮手。帮手会被射程内的炮塔打，也可以直接点它，打跑有金币奖励（越强奖励越多）。
   - **不会无限拖下去**：猛鬼最多逃 3 次，经济好、火力够的话不靠道具也能把它磨死；想更快结束可以用**斩杀道具**：一共 14 种，每局随机出现 4 种，放在建造面板「输出」列表的最下面（房间造满时，点任意建筑也能在面板底部看到）。猛鬼 Lv.4 以后才能用，买了马上生效、不占格子，同一种每用一次贵 30%。有天罚（扣 12%）、斩鬼剑（残血时斩 25%）、雷暴符、镇魂钟（震晕）、冰封术、业火（灼烧）、破甲咒（易伤）、追魂箭（破隐身）、吸魂瓶（吸血补门）、驱鬼爆竹（清小鬼和帮手）、封印符（下次回不了血）、金钱镖（按花的钱算伤害）、陨石（延迟大伤害）、时停。有钱的室友也会用，但全楼每 20 秒最多一个室友用。
   - **不会一直盯一个人**：猛鬼会记得刚砸过谁、砸过几次，更倾向换一家。
12. **室友互动**：鬼砸你的门时可以点「求救」。室友像真人一样有的会送金币，有的回「没钱了」「加油！」「我自己都在挨打」，也可能没人理你。室友快撑不住时头像上会冒出「救命」，点他头像进房间就能送金币帮他修门；在他房间里点建筑、床和门，可以查看等级、伤害、射程、品质、天赋等信息。
13. **胜负**：没有时间限制。你的门被砸破就输，把两只鬼都打死就赢（会放烟花）。
14. **操作**：拖动可以自由移动地图。底部是所有玩家的头像，自己在第一个，点一下就跳到那间房；正在挨打的人头像会亮红并显示「被打」。右下角「全图」可以看整栋楼。

## 局外成长

- **眠币**：只在商城里显示。每局结算会列出明细：参与、胜利、名次、坚持时间、伤害、今日首胜（+60）、连胜、打跑帮手、开礼盒、拍小鬼。
- **商城**：用眠币买床单（15 款）、门（12 款）和头像框（13 款）皮肤，只改外观。室友有时也会穿皮肤。
- **每日任务**：每天从 16 种里随机 4 个，玩的时候完成就自动发眠币（在商城的「每日任务」页看进度）。
- **成就**：25 个成就（包括屠魔、三连胜、天罚使者、传说降临、段位成就等），解锁时弹出提示并奖励眠币。
- **战绩图**：结算页可以生成一张战绩图片，长按保存或直接分享。

## 画面风格

扁平卡通手绘风：所有按钮都是粗描边、略带歪扭的贴纸造型，图标全部是和建筑同一画风的手绘小图（不用 emoji）。匹配界面三人一行。

## 声音

全部由 Web Audio 实时合成，经过压限器整体加响；每种建筑、猛鬼的招式、礼盒、求救都有自己的音效，背景音乐在鬼打你时会变紧张，还有中文语音播报。暂停菜单里可以分别调背景音乐、音效、语音的音量，开关震动。

## 手机 App 体验

- 支持「添加到主屏幕」，从桌面图标打开就是全屏，没网也能打开。
- 切出去时游戏会自动暂停，回来点「继续游戏」接着玩。

## 运行

纯静态网页，没有依赖。直接用浏览器打开 `index.html`，或者：

```bash
python3 -m http.server 8000
```

（离线缓存和添加到主屏幕需要通过 http/https 打开。）开发调试时在网址后面加 `#fast` 可以 6 倍速运行。

## 文件

- `index.html`：整个游戏（界面、逻辑、绘制、音效都在这一个文件里）
- `manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png`：添加到主屏幕和离线缓存用
