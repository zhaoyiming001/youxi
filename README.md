# 躺平发育

网页版「躺平发育」宿舍塔防小游戏：躺在床上赚金币和电力，升级床和门，造建筑、用道具，扛住越来越强的猛鬼，坚持到天亮。手机竖屏优先，电脑也能玩。

**在线试玩：** https://zhaoyiming001.github.io/youxi/

## 玩法

1. **选房（25 秒）**：点一间空宿舍，角色会走到床上躺下。5 个室友（阿强、小美、胖虎、老王、甜甜）也在抢房间。
2. **两种资源**：金币靠床和招财猫产出；电力靠游戏机产出，床、门、建筑的高级升级都要电。
3. **床和门**：床 9 级（2 → 120 金币/秒），门 9 级（300 → 60000 耐久），面板里会显示升级回本时间。
4. **7 种建筑**（每间房 9 个空位）：
   | 建筑 | 作用 |
   | --- | --- |
   | 炮台 | 猛鬼砸你门时自动开火 |
   | 电磁炮 | 每 2 秒一道高伤闪电 |
   | 游戏机 | 产电力 |
   | 招财猫 | 额外产金币 |
   | 维修台 | 持续修门 |
   | 冰箱 | 减慢猛鬼砸门速度 |
   | 镜子 | 反弹砸门伤害 |
5. **5 种道具**（底部道具栏，有冷却，价格随猛鬼等级上涨）：修理包、冰冻符、金钟罩、天雷、鸡血。电脑上可按 1–5 快捷使用。
6. **猛鬼**：23:00 出动，挑弱门砸，每隔一段时间升级。Lv.3 学会「重击」，Lv.5 学会「干扰」建筑，Lv.8 学会「狂暴」。血量低于 25% 会逃回鬼井回血，从你门口被打跑时你会拿到击退奖励。
7. **胜利**：打死猛鬼，或者坚持到 06:00。三档难度：简单 / 普通 / 噩梦，各自记录最佳成绩。

声音全部由 Web Audio 实时合成：背景音乐盒摇篮曲（猛鬼来砸门时会加快并加入心跳）、各类建筑和道具音效。暂停菜单里可以分别开关音乐、音效和震动。

## 运行

纯静态单文件，没有依赖。直接用浏览器打开 `index.html`，或者：

```bash
python3 -m http.server 8000
```

开发调试时在网址后面加 `#fast` 可以 6 倍速运行。
