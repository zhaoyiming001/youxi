# 眠仓计划

网页版宿舍塔防小游戏，玩法参考「躺平发育」：匹配 6 人宿舍，躺在床上赚金币和电力，造建筑守门，赶在鬼越砸越强之前把它打死。手机竖屏优先，电脑也能玩，还能添加到手机桌面当 App 用。

**在线试玩：** https://zhaoyiming001.github.io/youxi/

## 玩法

1. **匹配**：自动匹配 5 个室友，名字从 100 个里随机，头像有多种发型、配饰和表情。室友每局随机分成大佬、普通和摸鱼三种，强弱不一样。
2. **开局天赋**：匹配成功后从 3 张随机天赋卡里选 1 张（10 秒不选就随机），比如床收入 +30%、射程 +30、门耐久 +30%、礼盒更勤、挨打赚钱等，一共 14 种。室友也各有一个。
3. **选房（20 秒）**：点一间空宿舍，角色走到床上躺下，开始产金币。
4. **资源**：金币来自床、游戏机和招财猫；电力来自游戏机和发电机。
5. **25 种建筑**（每间房 13 个空位）。炮台、游戏机、发电机、招财猫、维修台、冰箱 6 种基础建筑每局都有；其余 19 种每局随机抽 11 种，标着「本局限定」。按价格分三类：
   - 只要金币：炮台、游戏机、发电机、维修台等基础建筑
   - 金币 + 电力：加农炮、激光炮、闪电塔、狙击台、喷火器、存钱罐、能量罩、镜子、电网、吸血藤、冰箱、音响等
   - 只要电力：天雷台、毒雾机、招财树、金钟、冰冻塔、符咒台、镇鬼阵、稻草人
   输出建筑的射程从门口算起，随等级变远，升高后能帮邻居打鬼。建筑 Lv.4 起有钢底座，Lv.7 起换成发光的金底座。钱和电够升级时，建筑、床和门上会出现绿色升级箭头。
6. **随机礼盒**：夜里每隔半分钟左右，房间里会掉下一个礼盒，14 秒内点开有奖：金币袋、充电宝、修理箱、加班费（收入翻倍）、鸡血（攻速提升）、冰冻弹、升级券。
7. **猛鬼**：每砸一次门涨一点经验，砸得越多升得越快、体型越大。Lv.3 学会重击，Lv.5 学会干扰建筑，Lv.8 学会狂暴。残血时会逃回鬼井回血，12 分钟后暴走，不再逃跑。每局猛鬼的底子略有不同（偏强的更多），但不会显示出来。另外每晚的猛鬼外形和招式不同（开局会提示）：
   - 普通：一个劲砸门
   - 隐身：时不时隐身几秒，炮塔打不到
   - 召唤：放小鬼去砸别人的门，点一下小鬼就能拍散它
   - 拆家：砸门时把建筑打掉一级
8. **室友互动**：鬼砸你的门时可以点「求救」，室友会送金币；室友快撑不住时头像上会冒出「救命」，点他头像进房间就能送金币帮他修门。
9. **胜负**：没有时间限制。你的门被砸破就输，把鬼打死就赢（会放烟花）。
10. **操作**：拖动可以自由移动地图。底部是所有玩家的头像，自己在第一个，点一下就跳到那间房；正在挨打的人头像会亮红并显示「被打」。右下角「全图」可以看整栋楼。

## 局外成长

- **眠币**：每局结束按名次、坚持时间和伤害发眠币。
- **衣柜**：用眠币买床单、门和头像框皮肤，只改外观。室友有时也会穿皮肤。
- **每日任务**：每天 3 个随机任务，完成后领眠币。
- **成就**：15 个成就，解锁时弹出提示并奖励眠币。
- **战绩图**：结算页可以生成一张战绩图片，长按保存或直接分享。

## 声音

全部由 Web Audio 实时合成，经过压限器整体加响；每种建筑、猛鬼的招式、礼盒、求救都有自己的音效，背景音乐在鬼打你时会变紧张，还有中文语音播报。暂停菜单里可以分别调背景音乐、音效、语音的音量，开关震动。

## 手机 App 体验

- 支持「添加到主屏幕」，从桌面图标打开就是全屏，没网也能打开。
- 切出去或者浏览器被关掉，下次打开首页会出现「继续上一局」，从刚才的进度接着玩。

## 运行

纯静态网页，没有依赖。直接用浏览器打开 `index.html`，或者：

```bash
python3 -m http.server 8000
```

（离线缓存和添加到主屏幕需要通过 http/https 打开。）开发调试时在网址后面加 `#fast` 可以 6 倍速运行。

## 文件

- `index.html`：整个游戏（界面、逻辑、绘制、音效都在这一个文件里）
- `manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png`：添加到主屏幕和离线缓存用
