# 躺平发育

一款网页版的「躺平发育」塔防小游戏：躺在宿舍床上赚金币，升级门和床，造炮台，扛住越来越强的猛鬼，坚持到天亮。

**在线试玩：** https://zhaoyiming001.github.io/youxi/

## 玩法

1. **选房（25 秒）**：点一间空宿舍，角色会自己走到床上躺下。另外 5 个室友（阿强、小美、胖虎、老王、甜甜）也在抢房间。
2. **躺平发育**：躺着就自动产金币。点**床**升级产量，点**门**升级耐久或花钱修门，点房间里的**空地**造建筑：
   - 炮台：猛鬼砸你的门时自动开火
   - 游戏机：发电，高级升级需要电力
   - 维修台：持续修门
   - 冰箱：减慢猛鬼砸门的速度
3. **猛鬼**：23:00 从鬼井爬出来，专挑薄弱的门砸。门破了，房间里的人就被抓走。它每 35 秒升一级，血量掉到 25% 以下会逃回鬼井回血。
4. **胜利条件**：打死猛鬼，或者坚持到早上 06:00。

## 运行

纯静态单文件，没有依赖。直接用浏览器打开 `index.html`，或者：

```bash
python3 -m http.server 8000
```

开发调试时在网址后面加 `#fast` 可以 6 倍速运行。
