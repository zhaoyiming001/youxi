# 躺平发育

网页版宿舍塔防小游戏，玩法参考「躺平发育」：匹配 8 人宿舍，躺在床上赚金币和电力，造建筑、用道具，赶在猛鬼越砸越强之前把它打死。手机竖屏优先，电脑也能玩。

**在线试玩：** https://zhaoyiming001.github.io/youxi/

## 玩法

1. **匹配**：自动匹配 7 个室友（名字和表情头像随机），一共 8 间宿舍上下两列排开，中间是走廊，最下面是鬼井。
2. **选房（20 秒）**：点一间空宿舍，角色走到床上躺下，开始产金币。
3. **资源**：
   - 金币：床（12 级）、游戏机、招财猫产出
   - 电力：游戏机、发电机产出，用来解锁高级升级
4. **13 种建筑**（每间房 13 个空位，按「输出 / 经济 / 防御 / 控制」分类）：

   | 分类 | 建筑 |
   | --- | --- |
   | 输出 | 炮台、加农炮（震晕）、激光炮（越照越痛）、闪电塔（麻痹） |
   | 经济 | 游戏机（电 + 金币）、发电机、招财猫 |
   | 防御 | 维修台、能量罩、镜子（反伤）、电网（电击） |
   | 控制 | 冰箱（减速）、符咒台（增伤） |

   输出建筑的射程从门口算起，随等级变远：大约 3 级能打到对门，再往上能帮隔壁打鬼。
5. **8 种道具**（底部道具栏，有冷却，价格随猛鬼等级上涨，电脑上按 1–8）：修理包、冰冻符、金钟罩、天雷、鸡血、稻草人（把猛鬼骗去别人家）、闹钟（立刻拿 25 秒金币）、充电宝（金币换电）。
6. **猛鬼**：每砸一次门涨一点经验，砸得越多升得越快。金钟罩、冰冻、减速都能拖慢它升级。Lv.3 学会重击，Lv.5 学会干扰建筑，Lv.8 学会狂暴。血量低于 25% 会逃回鬼井回血，逃跑路上会被各家炮塔追着打。
7. **胜负**：没有时间限制。你的门被砸破就输；把猛鬼打死就赢。
8. **串门**：点「全图」看整栋楼，点任意房间可以去看别人的布置，点「回我房间」回来。猛鬼来砸你门时会自动切回来。

声音全部由 Web Audio 实时合成，每种建筑和道具都有自己的音效。暂停菜单里可以分别开关音乐、音效和震动。

## 运行

纯静态单文件，没有依赖。直接用浏览器打开 `index.html`，或者：

```bash
python3 -m http.server 8000
```

开发调试时在网址后面加 `#fast` 可以 6 倍速运行。
