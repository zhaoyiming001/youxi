# 眠仓计划

网页版宿舍塔防小游戏，玩法参考「躺平发育」：匹配 6 人宿舍，躺在床上赚金币和电力，造建筑守门，赶在鬼越砸越强之前把它打死。手机竖屏优先，电脑也能玩。

**在线试玩：** https://zhaoyiming001.github.io/youxi/

## 玩法

1. **匹配**：自动匹配 5 个室友，名字从 100 个里随机，头像有多种发型、配饰和表情。室友每局随机分成大佬、普通和摸鱼三种，强弱不一样。
2. **选房（20 秒）**：点一间空宿舍，角色走到床上躺下，开始产金币。
3. **资源**：金币来自床、游戏机和招财猫；电力来自游戏机和发电机。
4. **18 种建筑**（每间房 13 个空位），按价格分三类：
   - 只要金币：炮台、游戏机、发电机、维修台等基础建筑
   - 金币 + 电力：加农炮、激光炮、闪电塔、能量罩、镜子、电网、冰箱等
   - 只要电力：天雷台、金钟、冰冻塔、符咒台、稻草人
   输出建筑的射程从门口算起，随等级变远，升高后能帮邻居打鬼。钱和电够升级时，建筑、床和门上会出现绿色升级箭头。
5. **猛鬼**：每砸一次门涨一点经验，砸得越多升得越快、体型越大。遇到弱的宿舍它会被越喂越强，所以要尽快把它打死。Lv.3 学会重击，Lv.5 学会干扰建筑，Lv.8 学会狂暴。残血时会逃回鬼井回血，12 分钟后暴走，不再逃跑。每局猛鬼的底子略有不同（偏强的更多），但不会显示出来。
6. **胜负**：没有时间限制。你的门被砸破就输，把鬼打死就赢。
7. **操作**：拖动可以自由移动地图。底部是所有玩家的头像，自己在第一个，点一下就跳到那间房；正在挨打的人头像会亮红并显示「被打」。右下角「全图」可以看整栋楼。

声音全部由 Web Audio 实时合成。暂停菜单里可以分别开关音乐、音效和震动。

## 运行

纯静态单文件，没有依赖。直接用浏览器打开 `index.html`，或者：

```bash
python3 -m http.server 8000
```

开发调试时在网址后面加 `#fast` 可以 6 倍速运行。
